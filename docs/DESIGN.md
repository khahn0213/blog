# 디자인 레퍼런스 분석 — tossplace.com

개인 블로그 프로젝트의 비주얼 톤을 정하기 위해 [tossplace.com](https://tossplace.com)(토스플레이스)의 디자인 스타일, 레이아웃, 인터랙션을 분석한 문서입니다. 블로그는 커머스/랜딩 사이트와 성격이 다르지만, "톤앤매너·타이포·인터랙션 문법"을 가져와 블로그에 맞게 변형하는 것을 목표로 합니다.

## 1. 전체 인상 요약

- **다크 히어로 + 라이트 콘텐츠**의 명확한 구간 전환. 상단 히어로~기능 소개 구간은 완전한 블랙(`#000000`) 배경에 화이트 텍스트로 몰입감과 고급스러움을 주고, 신뢰/사회적 증거(수상 내역, 고객사 로고 등) 구간부터는 화이트/라이트 그레이로 전환해 가독성과 신뢰감을 준다.
- **넓은 여백과 큰 타이포그래피** 중심의 미니멀한 레이아웃. 텍스트는 항상 좌측 정렬 2줄 이내의 굵은 헤드라인 + 1~2줄의 옅은 서브카피 조합.
- **디바이스 목업(실기기 스크린샷)** 을 활용해 실제 제품 화면을 보여주는 방식으로 신뢰도를 높임. 블로그에도 "실제 화면 미리보기" 방식으로 응용 가능.
- **알약형(pill) 버튼**과 **큰 라운드 카드**가 전체 UI의 기본 형태 언어. 각지지 않고 둥근 형태로 부드러운 인상을 줌.
- **스크롤 기반 스토리텔링**: 섹션마다 하나의 메시지 + 하나의 비주얼만 보여주고 다음 섹션으로 자연스럽게 이어지는 구조 (한 화면 = 한 메시지).

## 2. 색상 팔레트

| 용도 | 색상 | 비고 |
|---|---|---|
| 히어로/기능 섹션 배경 | `#000000` | 순수 블랙, 몰입형 섹션 |
| 기본 배경(라이트 섹션) | `#FFFFFF` | 사회적 증거·상세 정보 구간 |
| 서브 배경(카드 영역) | `#F6F7F9` | 연한 그레이, 카드 그리드 배경 |
| 서브 배경2 | `#F2F4F6` | 버튼 비활성/보조 영역 |
| 브랜드 포인트 컬러 | `#3182F6` (Toss Blue) | 주요 CTA 버튼, 강조 텍스트 |
| 본문 텍스트(라이트 배경) | `#333D4B` 계열 | 짙은 네이비 그레이, 순수 검정 대신 사용 |
| 보조 텍스트 | `rgba(0,12,30,0.8)` / `#4E5968` | 내비게이션, 설명문 |
| 푸터 배경 | `#333D4B` | 다크 네이비 (블랙과 다른 톤으로 마무리감) |

**포인트**: 검정·흰색의 강한 대비 위에 브랜드 블루 하나만 포인트로 쓰고, 회색은 톤온톤(그레이 스케일 3~4단계)으로 세분화해서 사용한다. 색을 많이 쓰지 않고 "여백 + 타이포 크기"로 위계를 만든다.

## 3. 타이포그래피

- 서체: `Toss Product Sans` 커스텀 폰트 기반, 폴백으로 `Apple SD Gothic Neo`, `Noto Sans KR` 등 시스템 한글 폰트 사용.
- 섹션 헤드라인: **48px, font-weight 700~800**, 2줄 이내로 짧게 끊어 큰 임팩트를 줌 (예: "440,000 매장의 선택", "우리 매장 분위기가 묻어나는 / 첫 화면 꾸미기").
- 서브 카피: 16px 내외, 연한 회색, 헤드라인과 8~16px 정도의 좁은 간격으로 밀착 배치.
- 문장은 항상 **짧고 구어체에 가까운 한국어 카피** ("~해요", "~어요" 체) 사용 — 딱딱한 설명체보다 친근한 톤.
- 숫자(통계)는 큰 사이즈로 단독 강조 (`440,000 매장의 선택`, `주문 수 3.2배`).

블로그에 적용한다면: 포스트 제목은 32~40px 굵게, 홈 히어로 문구가 있다면 위와 같은 큰 타이포 + 짧은 카피 문법을 적용.

제목 폰트
```

@font-face {
    font-family: 'GMarketSans';
    src: url('https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_2001@1.1/GmarketSansLight.woff') format('woff');
    font-weight: 300;
    font-display: swap;
}
```

## 4. 레이아웃 패턴

### 4.1 반복되는 "기능 소개" 섹션 구조
페이지 대부분이 아래 패턴의 반복으로 구성됨:

```
[한 화면 100vh 내외]
- 좌(또는 우): 굵은 2줄 헤드라인 + 옅은 서브카피
- 반대편: 실기기 목업 이미지(전화기/태블릿/노트북), 화면 내부는 실제 제품 UI 스크린샷
- 섹션마다 좌우 배치가 번갈아 바뀜 (지그재그 레이아웃)
- 배경은 검정 유지, 디바이스 이미지만 교체되며 스토리가 진행됨
```

### 4.2 스티키 하단 바
스크롤 내내 화면 하단에 고정된 바(흰색 pill 배경) 안에 "이벤트" 뱃지 + CTA 버튼 1~2개가 항상 노출됨. 우측 하단에는 원형 플로팅 상담원 아이콘이 별도로 고정.

### 4.3 헤더
- 상단 고정(sticky) 헤더, 로고 + 햄버거 메뉴만 노출되는 미니멀 구성.
- 배경이 어두운 섹션 위에서는 로고/아이콘이 흰색, 밝은 섹션으로 전환되면 로고/아이콘이 검정으로 자동 전환(적응형 헤더).

### 4.4 멀티 디바이스 합성 & 확대 아이콘
한 이미지 안에 태블릿+휴대폰을 겹쳐 배치해 "여러 기기에서 연동된다"는 메시지를 시각적으로 전달. 이미지 위에 돋보기(zoom) 아이콘을 올려 "확대해서 볼 수 있다"는 인터랙션 힌트를 줌.

### 4.5 카드 그리드 (신뢰 구간)
라이트 섹션에서는 12~16px 라운드의 흰색 카드가 그리드로 배치되고, 카드 그림자는 `0 2px 30px rgba(0,27,55,0.1)` 같은 넓고 옅은 블러 그림자를 사용해 종이가 떠 있는 듯한 느낌을 줌.

### 4.6 멀티 플랫폼 노출 섹션
"윈도우 / 안드로이드 / 아이패드 / 맥북"처럼 지원 플랫폼을 pill 뱃지 + 아이콘으로 나열하고, 그 아래 실제 기기 라인업 이미지를 한 화면에 배치.

## 5. 버튼 & 인터랙션 컴포넌트

| 요소 | 스타일 |
|---|---|
| Primary CTA | 배경 `#3182F6`, 흰 텍스트, `border-radius: 100px`(완전한 알약형), font-weight 600 |
| Secondary CTA | 배경 `#F2F4F6`(연한 회색), 짙은 회색 텍스트, 동일한 pill 라운드 |
| 카드/이미지 | `border-radius: 16px`, 부드러운 대형 블러 그림자 |
| 전환 효과 | 대부분의 상호작용 요소에 `transition: all`로 색상·그림자 변화가 부드럽게 처리됨 (hover/scroll 전환 시 끊김 없음) |
| 스크롤 유도 | 배경 이미지 위에 희미하게 겹쳐진 "끝까지 스크롤 해주세요" 같은 유희적 마이크로카피로 다음 콘텐츠를 유도 |
| 플로팅 위젯 | 화면 우하단 고정된 원형 상담 아이콘 — 스크롤 내내 위치 고정, 페이지 전반에서 클릭 가능 |

## 6. 개인 블로그에 적용할 때 가이드

토스플레이스는 전환(상담 신청·다운로드)이 목적인 커머스 랜딩이고, 블로그는 콘텐츠 소비가 목적이므로 그대로 복제하기보다 아래처럼 **문법만 차용**하는 것을 권장합니다.

1. **홈 히어로**: 검정 배경 + 큰 타이포(예: 블로그 대표 문구나 최근 인기 글 통계 "이번 달 3,200명이 읽었어요")로 시작 — 이후 스크롤하면 라이트 배경의 게시글 목록으로 전환.
2. **포스트 상세 페이지**: 다크 히어로 대신, 대표 이미지를 풀블리드로 크게 배치하고 그 위에 큰 제목(48px급) + 옅은 메타정보(작성일·카테고리) 오버레이.
3. **버튼/태그**: 카테고리·태그 칩(chip)을 pill 형태(`border-radius: 100px`)로 통일, 강조 액션(구독하기, 공유하기)은 포인트 컬러의 pill 버튼으로.
4. **카드형 리스트**: 게시글 카드에 16px 라운드 + 옅은 블러 그림자를 적용해 리스트 자체를 "떠 있는 카드"처럼 구성.
5. **플로팅 요소**: 우하단에 "맨 위로 가기" 또는 "다크모드 토글" 같은 원형 플로팅 버튼을 고정.
6. **색상**: 블랙/화이트 대비를 메인 골격으로 하고, 포인트 컬러 1개(블로그 브랜드 컬러)만 선택해 CTA·링크·강조 텍스트에 일관되게 사용. 회색은 2~3단계로만 제한.
7. **타이포**: 시스템 폰트(Pretendard, Noto Sans KR 등) 기반으로 헤드라인은 크고 굵게, 본문은 충분한 줄간격(1.6~1.8)으로 가독성 확보.
8. **인터랙션은 과하지 않게**: 토스처럼 매 섹션 스크롤 애니메이션까지 구현하기보다, 우선은 hover/전환(transition) 정도만 부드럽게 처리하고 (Start from Small 원칙에 맞춰) 이후 여유가 생기면 스크롤 인터랙션을 단계적으로 추가.

## 7. 참고 스크린샷 근거 (분석 시점 캡처 기준)

- 히어로: 통계 강조형 카피 + 사진 콜라주 배경 + pill 버튼 2개
- 기능 소개 반복 섹션 6~7개 (좌우 교차 배치, 디바이스 목업)
- 멀티 플랫폼 지원 섹션 (OS 아이콘 pill + 디바이스 라인업)
- 사회적 증거 섹션 (라이트 배경 전환, "예비 창업자 선호도 1위" 등 타이틀 단독 강조)
- 관련 제품 카드 그리드 (라운드 카드 + 옅은 그림자)
- 푸터 (다크 네이비, 법적 정보 + SNS 아이콘)
