# 개인 블로그 사이트맵 & 기능 정의

바이브코딩으로 만드는 개인 블로그 프로젝트의 초기 기획 문서입니다.
사용자(방문자) 화면과 관리자 화면의 사이트맵, 그리고 각 화면에 필요한 기본 기능을 정리합니다.

## 0. 기술 스택

- **GitHub**: 소스 코드 저장소, 버전 관리, (선택) GitHub Actions로 CI
- **Vercel**: 배포/호스팅, GitHub 연동 시 브랜치/PR별 프리뷰 배포 자동화
- **Firebase**: 데이터 저장 및 인프라
  - Firestore: 게시글, 카테고리, 태그, 댓글, 통계 원시 이벤트 저장
  - Firebase Authentication: 관리자 로그인
  - Firebase Storage: 이미지 등 미디어 업로드
  - Google Analytics for Firebase (GA4): 방문자 통계 수집의 메인 소스
  - (선택) Cloud Functions: GA4 Data API 호출·집계, 일별 배치 집계, 리포트 발송

## 1. 전체 구조 개요

```
/                        (블로그 홈)
├── /posts/[slug]        (게시글 상세)
├── /category/[slug]     (카테고리별 목록)
├── /tag/[slug]          (태그별 목록)
├── /search              (검색 결과)
├── /about               (소개 페이지)
├── /archive             (전체 글 아카이브)
└── /admin               (관리자 영역, 로그인 필요)
    ├── /admin/login
    ├── /admin/dashboard
    ├── /admin/posts
    │   ├── /admin/posts/new
    │   └── /admin/posts/[id]/edit
    ├── /admin/categories
    ├── /admin/tags
    ├── /admin/comments
    ├── /admin/media
    ├── /admin/analytics
    │   ├── /admin/analytics/realtime
    │   ├── /admin/analytics/posts
    │   ├── /admin/analytics/audience
    │   └── /admin/analytics/acquisition
    └── /admin/settings
```

## 2. 사용자(방문자) 화면 사이트맵

### 2.1 홈 (`/`)
- 최신 게시글 목록 (썸네일, 제목, 요약, 작성일, 카테고리)
- 페이지네이션 또는 무한 스크롤
- 인기 글 / 추천 글 섹션 (실시간·주간 인기글 통계 기반)
- 카테고리·태그 내비게이션

### 2.2 게시글 상세 (`/posts/[slug]`)
- 제목, 작성일, 수정일, 카테고리, 태그
- 본문 (마크다운 렌더링, 코드 하이라이팅 지원)
- 목차(TOC) 자동 생성 (선택)
- 이전글/다음글 네비게이션
- 댓글 영역
- 공유하기 버튼 (링크 복사, SNS 공유) — 클릭 시 공유 이벤트 트래킹
- 관련 글 추천 (선택)
- 조회수 표시 (선택, 노출 여부는 설정에서 on/off)
- **통계 이벤트 트래킹 (필수)**
  - 페이지뷰(page_view)
  - 스크롤 깊이(25/50/75/100%) 이벤트
  - 체류 시간 / 읽기 완료 이벤트
  - 공유 버튼 클릭, 외부 링크 클릭 이벤트
  - UTM 파라미터 자동 캡처 (유입 캠페인 분석용)

### 2.3 카테고리별 목록 (`/category/[slug]`)
- 해당 카테고리 게시글 목록
- 정렬 옵션 (최신순, 인기순 — 조회수 통계 기반)

### 2.4 태그별 목록 (`/tag/[slug]`)
- 해당 태그가 달린 게시글 목록

### 2.5 검색 (`/search`)
- 제목/본문 키워드 검색
- 검색 결과 목록 (하이라이팅)
- 검색어 자체를 통계 이벤트로 기록 (내부 검색어 분석용)

### 2.6 소개 (`/about`)
- 작성자 프로필, 연락처, SNS 링크 등 정적 페이지

### 2.7 아카이브 (`/archive`)
- 연도/월별로 그룹핑된 전체 글 목록

### 2.8 공통 요소
- 헤더: 로고, 메인 내비게이션, 검색 아이콘, 다크모드 토글
- 푸터: 저작권, SNS 링크, RSS 구독 링크
- 반응형 레이아웃 (모바일 대응)
- 전체 페이지 공통 통계 트래킹 스크립트 삽입 (필수, GA4 gtag + 커스텀 이벤트)
- 쿠키/트래킹 동의 배너 (선택, 필요 시 GDPR/개인정보 대응)

## 3. 관리자 화면 사이트맵

### 3.1 로그인 (`/admin/login`)
- Firebase Authentication 기반 아이디/비밀번호 로그인
- (선택) OAuth 로그인 (GitHub 등)

### 3.2 대시보드 (`/admin/dashboard`)
- 전체 게시글 수, 임시저장 수, 댓글 수 요약
- 최근 활동 (최근 작성/수정 글, 최근 댓글)
- **방문자 통계 요약 (필수, `/admin/analytics` 바로가기 카드)**
  - 실시간 활성 방문자 수 (최근 5분 기준)
  - 오늘/주간/월간 방문자 수 및 전 기간 대비 증감률
  - 페이지뷰 추이 그래프 (일별, 최근 30일)
  - 인기 게시글 Top 5 (오늘/주간 기준 토글)
  - 평균 체류 시간, 이탈률(bounce rate) 요약 지표

### 3.3 게시글 관리 (`/admin/posts`)
- 게시글 목록 (검색, 필터: 카테고리/상태(발행·임시저장)/기간)
- 새 글 작성 (`/admin/posts/new`)
  - 마크다운 에디터 (실시간 미리보기)
  - 제목/슬러그/요약/대표이미지 입력
  - 카테고리/태그 지정
  - 임시저장 / 발행 / 예약발행
- 글 수정 (`/admin/posts/[id]/edit`)
  - 글 상세 편집 화면에서 해당 글의 조회수/유입 경로 미니 통계 확인 가능
- 글 삭제 (soft delete 권장)

### 3.4 카테고리 관리 (`/admin/categories`)
- 카테고리 생성/수정/삭제
- 카테고리 순서 변경

### 3.5 태그 관리 (`/admin/tags`)
- 태그 생성/수정/삭제 (병합 기능 선택)

### 3.6 댓글 관리 (`/admin/comments`)
- 전체 댓글 목록
- 승인/스팸 처리/삭제
- 답글 작성

### 3.7 미디어 관리 (`/admin/media`)
- Firebase Storage 기반 이미지 업로드/목록/삭제
- 업로드된 이미지 URL 복사

### 3.8 방문자 통계 (`/admin/analytics`) — 필수, 4개 하위 탭으로 강화

#### 3.8.1 개요 (`/admin/analytics`)
- 기간 선택기 (오늘/7일/30일/90일/커스텀 범위, 이전 기간 대비 비교)
- 핵심 지표 카드: 방문자 수(순방문자/총방문), 페이지뷰, 평균 세션 시간, 이탈률
- 일별 방문자·페이지뷰 추이 그래프 (기간 비교 오버레이)

#### 3.8.2 실시간 (`/admin/analytics/realtime`) — 신규
- 현재 접속 중인 방문자 수 (수 초 단위 갱신)
- 실시간으로 조회되고 있는 게시글 목록
- 실시간 유입 국가/디바이스 분포

#### 3.8.3 게시글별 통계 (`/admin/analytics/posts`) — 강화
- 게시글별 조회수 랭킹 (기간별 정렬, 페이지네이션)
- 게시글별 평균 체류 시간 / 스크롤 완료율(읽기 완료율)
- 게시글별 유입 경로 Top 3
- 게시글 대비 카테고리·태그별 합산 통계

#### 3.8.4 유입 경로 (`/admin/analytics/acquisition`) — 신규
- 유입 채널 분류: 검색(SEO), 소셜, 직접 방문, 리퍼럴, 캠페인(UTM)
- Referrer 도메인별 순위
- UTM 캠페인별 유입/전환 통계 (source/medium/campaign)
- 내부 검색어 Top 검색어 랭킹

#### 3.8.5 방문자 속성 (`/admin/analytics/audience`) — 신규
- 국가/지역별 방문자 분포 (지도 또는 랭킹 리스트)
- 기기 유형(모바일/PC/태블릿), OS, 브라우저 비율
- 신규 방문자 vs 재방문자 비율
- 방문 시간대(요일×시간) 히트맵

#### 3.8.6 공통 기능
- CSV/이미지 내보내기 (그래프·표 export)
- 주간/월간 통계 요약 이메일 리포트 자동 발송 (선택, Cloud Functions + 이메일 발송 연동)
- Firebase Analytics(GA4) Data API 연동, 관리자 화면 자체 대시보드로 시각화

### 3.9 설정 (`/admin/settings`)
- 블로그 제목/설명/프로필 정보 수정
- 소셜 링크 관리
- SEO 기본값 (메타 설명, OG 이미지) 설정
- 테마/다크모드 기본값
- 통계 관련 설정: 조회수 공개 노출 여부, 통계 리포트 이메일 수신 설정, 트래킹 제외 IP(관리자 본인) 설정

## 4. MVP 우선순위 제안 (Start from Small)

1단계 (최소 기능)
- 홈 목록 + 게시글 상세
- Firebase Authentication 기반 관리자 로그인 + 글 작성/수정/삭제 (마크다운 에디터, Firestore 저장)
- 카테고리 분류
- GitHub 저장소 + Vercel 배포 파이프라인 연결
- **방문자 통계 기본기**: GA4 gtag 스크립트 삽입 (전 페이지 page_view 트래킹), 관리자 대시보드에 오늘/주간 방문자 수·페이지뷰 요약만 우선 노출

2단계
- 태그, 검색, 아카이브 페이지
- 댓글 기능
- `/admin/analytics` 개요 탭 + 게시글별 통계 탭 구현 (조회수 랭킹, 체류 시간)
- 커스텀 이벤트 트래킹 추가 (스크롤 깊이, 공유 클릭, 검색어 기록)

3단계
- 미디어 관리(Firebase Storage), SEO 설정, 예약발행
- **방문자 통계 고도화**: 실시간 탭, 유입 경로 탭(UTM/Referrer), 방문자 속성 탭(국가·기기·신규/재방문), CSV 내보내기, 주간 리포트 이메일 자동 발송

## 5. 결정 필요 사항 (추후 논의)
- 프레임워크 선택 (예: Next.js — Vercel과 궁합이 좋아 기본 후보로 추천)
- Firestore 데이터 모델 설계 (posts, categories, tags, comments, analytics_events 컬렉션 구조)
- 단일 관리자 계정 vs 다중 사용자 인증 범위
- GA4 Data API 호출 주기/캐싱 전략 (실시간 vs 배치 집계, Cloud Functions 필요 여부)
- 통계 이메일 리포트 발송 여부 및 발송 채널 (Firebase Extensions, SendGrid 등)
- 개인정보/쿠키 동의 배너 필요 여부 (방문 지역, 관련 법규에 따라 결정)
